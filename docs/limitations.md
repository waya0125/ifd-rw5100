# 制限と動作

## 確認した環境とカード

| 項目 | 内容 |
|------|------|
| OS | Ubuntu 26.04.1 LTS（カーネル 7.0.0） |
| pcsc-lite | pcscd 2.4.1 |
| リーダー | SHARP RW-5100（`04dd:9259`）1 台（Windows の公式ドライバーとの比較には別の 1 台を使用） |

| カード | プロトコル | 結果 |
|--------|-----------|------|
| T=1 のカード（2 種類、ETC カードを含む） | T=1 | 認識・抜き挿しの検出・ATR・APDU が動作する。返事が数十バイトある APDU を続けてやり取りする用途でも動作した |
| 空の Java カード | T=0 | ATR は読めるが、APDU は使用できない（「T=0 のカード」を参照） |

## T=0 のカード

T=0 のカードでは APDU のやり取りができません。試した T=0 のカード（空の Java カード 1 枚）では、ATR は読めましたが、APDU を送るとリーダーが応答しなくなりました。Windows の公式ドライバーでも同じカードの電源投入の段階で失敗したため、RW-5100 自体が T=0 に対応していないとみられます。

## APDU の長さ

RW-5100 の枠の長さの欄が 1 バイトのため、送れる APDU は 255 バイトまでです。

## カードの電源

pcscd が電源を切ろうとしても、カードには電源が入ったままです。Windows の公式ドライバーも電源を切る命令を送らないため、同じ動作にしています。

リセットはカードに電源が入っていればウォームリセット（`D1 03`）、入っていなければ電源投入（`D1 00`）として送ります。

## カードの挿し方

- カードの向きが逆の場合は「カードなし」と表示されます（試した別のリーダーでは「応答なし」になりました）。
- カードを挿している途中に電源を入れようとすると、ATR を読めずに「応答なし」になることがあります。挿し終えてから抜き挿しし直すと読み取れます。

## pcscd の起動直後

pcscd が起動した直後の 1 秒ほどは、カードが入っていても「カードなし」と表示されることがあります。

## リーダーが応答しなくなった時

ドライバーが USB をリセットします。リーダーは USB に接続し直された扱いになり、pcscd が開き直します。試したときは 7 秒ほどで復帰しました。

USB をリセットしても復帰しない場合は、RW-5100 を抜いて挿し直してください。挿す USB ポートを変えると復帰した例もありました。
